🎨 HTML Colors

HTML colors are specified using predefined color names, or RGB, HEX, HSL, RGBA, or HSLA values. Colors can be applied to text, backgrounds, borders, and more.

📐 Ways to Specify Colors in HTML

🏷️ Color Names

HTML supports 140 standard color names. Here are the most common ones:

<p style="color: Tomato;">Tomato text</p>
<p style="color: DodgerBlue;">DodgerBlue text</p>
<p style="color: MediumSeaGreen;">Green text</p>

📟 Browser Output:

Tomato text

DodgerBlue text

Green text

🖌️ Background Color

Use the background-color property to set the background of any element.

<p style="background-color: Tomato; color: white; padding: 10px;">
  Tomato background
</p>

📟 Browser Output:

Tomato background

🔤 Text Color

Use the color property to set text color.

<p style="color: #8b5cf6;">Purple HEX text</p>
<p style="color: rgb(255, 99, 71);">Tomato RGB text</p>

🔲 Border Color

Use the border property to set border color, width, and style.

<p style="border: 3px solid Tomato; padding: 10px;">
  Text with tomato border
</p>

📟 Browser Output:

Text with tomato border

🔍 RGBA — Colors with Transparency

RGBA adds an Alpha channel (0 = fully transparent, 1 = fully opaque):

<p style="background: rgba(255, 99, 71, 0.3); padding: 10px;">
  30% opacity tomato background
</p>
<p style="background: rgba(255, 99, 71, 0.8); padding: 10px;">
  80% opacity tomato background
</p>

📟 Browser Output:

30% opacity tomato background

80% opacity tomato background
