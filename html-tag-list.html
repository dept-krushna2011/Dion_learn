📋 HTML Tag List

A complete reference of all HTML tags — from basic structure to advanced elements. Tags marked HTML5 are new in HTML5, and Deprecated tags should be avoided.

📄 Basic Structure Tags

TagDescriptionExample
<!DOCTYPE>Defines document type (must be first)<!DOCTYPE html>
<html>Root element of HTML page<html lang="en">
<head>Contains metadata/information<head>...</head>
<title>Page title (browser tab)<title>My Page</title>
<body>Visible page content<body>...</body>

🔤 Text & Headings

TagDescriptionExample
<h1> - <h6>Headings (h1 largest, h6 smallest)<h1>Title</h1>
<p>Paragraph<p>Text here</p>
<br>Single line break (self-closing)Line 1<br>Line 2
<hr>Horizontal rule / thematic break<p>Above</p><hr><p>Below</p>
<span>Inline container for styling<span style="color:red">Red</span>
<div>Block container for layout<div class="box"></div>

✂️ Text Formatting

TagDescription
<b>Bold text (visual only)
<strong>Important text (semantic, screen readers emphasize)
<i>Italic text (visual only)
<em>Emphasized text (semantic, screen readers stress)
<mark> HTML5Highlighted/marked text
<small>Smaller text (fine print)
<del>Deleted text (strikethrough)
<ins>Inserted text (underline)
<sub>Subscript (below line)
<sup>Superscript (above line)

🔗 Links & Media

TagDescriptionExample
<a>Hyperlink<a href="url">Click</a>
<img>Image (self-closing)<img src="pic.jpg" alt="desc">
<video> HTML5Video player<video src="movie.mp4" controls>
<audio> HTML5Audio player<audio src="song.mp3" controls>
<iframe>Inline frame (embed another page)<iframe src="page.html"></iframe>
<canvas> HTML5Drawing graphics via JavaScript<canvas id="myCanvas"></canvas>
<svg> HTML5Scalable Vector Graphics<svg>...</svg>

📋 Lists

TagDescription
<ul>Unordered list (bullet points)
<ol>Ordered list (numbered)
<li>List item (inside ul or ol)
<dl>Description list
<dt>Description term
<dd>Description details

📊 Tables

TagDescription
<table>Creates a table
<tr>Table row
<th>Table header cell (bold, centered)
<td>Table data cell
<thead>Table header group
<tbody>Table body group
<tfoot>Table footer group
<caption>Table caption/title

📝 Forms

TagDescription
<form>Form container
<input>Input field (many types)
<textarea>Multi-line text input
<button>Clickable button
<select>Dropdown list
<option>Option in select/datalist
<label>Label for an input
<fieldset>Groups form elements
<legend>Caption for fieldset
<datalist> HTML5Predefined options for input

🧱 Semantic Elements HTML5

TagDescription
<header>Header section
<nav>Navigation links
<main>Main content (only ONE per page)
<section>Thematic grouping
<article>Independent content
<aside>Sidebar / related content
<footer>Footer section
<figure>Self-contained content (image, diagram)
<figcaption>Caption for figure

⚙️ Meta, Style & Script

TagDescription
<meta>Metadata (charset, viewport, description)
<link>Links external resources (CSS, favicon)
<style>Internal CSS styles
<script>JavaScript code or file
<noscript>Fallback for browsers without JS
<base>Base URL for all relative links
