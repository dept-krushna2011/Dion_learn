🖼️ HTML SVG

SVG stands for Scalable Vector Graphics. It defines vector-based graphics in XML format that can be embedded directly in HTML. SVG images never lose quality when zoomed or resized!

🧠 Key Difference: Canvas = pixel-based (raster), drawn with JavaScript. SVG = vector-based (XML), drawn with HTML-like tags. SVG shapes are part of the DOM and can be styled with CSS!

📝 Basic SVG Example

<svg width="200" height="200">
  <circle cx="100" cy="100" r="80" fill="#8b5cf6" />
</svg>

🔷 Common SVG Shapes

ShapeElementKey Attributes
⭕ Circle<circle>cx, cy, r
⬜ Rectangle<rect>x, y, width, height, rx (rounded)
🔺 Polygon<polygon>points="x,y x,y x,y..."
📏 Line<line>x1, y1, x2, y2
✨ Ellipse<ellipse>cx, cy, rx, ry
📝 Text<text>x, y, fill, font-size

🎨 SVG Shapes Demo

<svg width="400" height="300">
  <!-- Rectangle -->
  <rect x="10" y="10" width="100" height="80" fill="#8b5cf6" rx="10"/>
  
  <!-- Circle -->
  <circle cx="200" cy="50" r="40" fill="#10b981"/>
  
  <!-- Triangle (polygon) -->
  <polygon points="300,10 380,80 300,80" fill="#f59e0b"/>
  
  <!-- Text -->
  <text x="10" y="150" fill="#0f172a" font-size="24" font-weight="bold">SVG is Awesome!</text>
</svg>

🆚 Canvas vs SVG — When to Use What

FeatureCanvasSVG
TypePixel-based (raster)Vector-based (XML)
ScalabilityLoses quality when zoomedNever loses quality
DOM AccessNo — single elementYes — each shape is accessible
CSS StylingLimitedFull CSS support
PerformanceBetter for many objects (games)Better for few objects (icons, logos)
Best ForGames, animations, image editingIcons, logos, charts, diagrams

💡 Simple Rule: Use SVG for logos, icons, and static graphics. Use Canvas for games, real-time animations, and heavy graphics.
