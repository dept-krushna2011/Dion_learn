🎨 HTML Canvas Reference

A complete reference of the most commonly used Canvas API methods and properties. Canvas provides a powerful drawing surface that you control with JavaScript.

🧠 Getting Started: First get the canvas element: const canvas = document.getElementById('myCanvas'); then get the 2D context: const ctx = canvas.getContext('2d');

🖌️ Colors & Styles

Property/MethodDescriptionExample
fillStyleFill color for shapesctx.fillStyle = 'red';
strokeStyleOutline color for shapesctx.strokeStyle = '#333';
lineWidthWidth of linesctx.lineWidth = 5;
lineCapLine end style: butt, round, squarectx.lineCap = 'round';
globalAlphaTransparency (0-1)ctx.globalAlpha = 0.5;

🔷 Drawing Shapes

MethodDescriptionExample
fillRect(x,y,w,h)Filled rectanglectx.fillRect(10,10,100,50);
strokeRect(x,y,w,h)Rectangle outlinectx.strokeRect(10,10,100,50);
clearRect(x,y,w,h)Clear rectangular areactx.clearRect(0,0,200,200);
beginPath()Start a new pathctx.beginPath();
moveTo(x,y)Move pen to pointctx.moveTo(50,50);
lineTo(x,y)Draw line to pointctx.lineTo(150,50);
arc(x,y,r,start,end)Draw circle/arcctx.arc(100,100,50,0,Math.PI*2);
fill()Fill current pathctx.fill();
stroke()Outline current pathctx.stroke();
closePath()Close current pathctx.closePath();

🔤 Text

Property/MethodDescriptionExample
fontFont style and sizectx.font = '30px Poppins';
textAlignHorizontal alignmentctx.textAlign = 'center';
fillText(text,x,y)Draw filled textctx.fillText('Hello',100,50);
strokeText(text,x,y)Draw outlined textctx.strokeText('Hello',100,50);

🖼️ Images & Transformations

MethodDescriptionExample

drawImage(img,x,y,w,h)Draw image with sizectx.drawImage(img,0,0,200,100);
scale(x,y)Scale drawingsctx.scale(2,2);
rotate(angle)Rotate drawingsctx.rotate(Math.PI/4);
translate(x,y)Move origin pointctx.translate(100,50);
save() / restore()Save/restore canvas statectx.save(); ... ctx.restore();

🌈 Gradients

// Linear gradient
const gradient = ctx.createLinearGradient(0,0,200,0);
gradient.addColorStop(0, 'red');
gradient.addColorStop(1, 'blue');
ctx.fillStyle = gradient;
ctx.fillRect(10,10,200,100);

// Radial gradient
const radial = ctx.createRadialGradient(100,50,10,100,50,80);
radial.addColorStop(0, 'yellow');
radial.addColorStop(1, 'green');
ctx.fillStyle = radial;
ctx.fillRect(10,130,200,100);

💡 Pro Tip: Always use beginPath() before starting a new shape. Without it, previous paths may interfere with your new drawings!
