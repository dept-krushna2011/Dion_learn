💾 HTML Web Storage

Web Storage lets you save data in the user's browser. It's like cookies but better — more storage, easier to use, and data stays on the device even after closing the browser!

🧠 In Simple Words: You can save information (like user preferences, shopping cart items, dark mode settings) directly in the browser. It stays there until you delete it!

📦 Two Types of Web Storage

TypeHow Long It LastsBest For
localStorage✅ Forever (until deleted)User preferences, settings, saved data
sessionStorage❌ Until tab is closedTemporary data (form drafts, one-time tokens)

📝 How to Use Web Storage — 4 Simple Commands

// 1. SAVE data
localStorage.setItem('name', 'John');

// 2. GET data
const name = localStorage.getItem('name');  // 'John'

// 3. REMOVE one item
localStorage.removeItem('name');

// 4. CLEAR everything
localStorage.clear();

That's it! Just 4 commands to remember. Replace localStorage with sessionStorage for temporary storage.
