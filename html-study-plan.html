📅 HTML Study Plan

Follow this 14-day study plan to learn HTML from scratch. Each day covers specific topics with practice exercises. Stay consistent and you'll master HTML in just 2 weeks!

🧠 How to Use: Study the topics each day, write code along with examples, and complete the practice exercises. Spend about 1-2 hours per day for best results.

📅 Week 1: HTML Fundamentals

📅 Day 1 — Getting Started

  • ✅ HTML HOME — What is HTML?
  • ✅ HTML Introduction — How the web works
  • ✅ HTML Editors — Install VS Code
  • ✍️ Practice: Create your first HTML file

📅 Day 2 — Building Blocks

  • ✅ HTML Basic — Document structure
  • ✅ HTML Elements — Tags & nesting
  • ✅ HTML Attributes — Adding information to tags
  • ✍️ Practice: Build a simple page with headings, paragraphs, links

📅 Day 3 — Text & Styling

  • ✅ HTML Headings & Paragraphs
  • ✅ HTML Styles — Inline CSS, colors, fonts
  • ✅ HTML Formatting — Bold, italic, mark, etc.
  • ✍️ Practice: Style a blog post with headings and formatted text

📅 Day 4 — Quotes, Comments & Colors

  • ✅ HTML Quotations — blockquote, q, cite
  • ✅ HTML Comments — Documenting code
  • ✅ HTML Colors — Names, HEX, RGB
  • ✍️ Practice: Add quotes and colored sections to your page

📅 Day 5 — Links & Images

  • ✅ HTML Links — Navigation, email links, bookmarks
  • ✅ HTML Images — src, alt, sizing
  • ✅ HTML Favicon — Browser tab icon
  • ✍️ Practice: Create a photo gallery page

📅 Day 6 — Tables & Lists

  • ✅ HTML Tables — Structure, colspan, rowspan
  • ✅ HTML Lists — ul, ol, description lists
  • ✍️ Practice: Create a timetable and a recipe list

📅 Day 7 — Review & Mini Project

  • ✅ Review all Week 1 topics
  • ✅ Take the HTML Quiz
  • ✍️ Project: Build a personal info page with everything learned

📅 Week 2: Advanced HTML

📅 Day 8 — Layout Basics

  • ✅ Block & Inline, Div, Classes, Id
  • ✅ HTML Layout — Semantic elements
  • ✍️ Practice: Create a page layout with header, nav, main, footer

📅 Day 9 — Interactive Elements

  • ✅ HTML Buttons, Iframes, JavaScript
  • ✅ HTML File Paths, Head element
  • ✍️ Practice: Embed a YouTube video and add buttons

📅 Day 10 — Forms Part 1

  • ✅ HTML Forms, Form Attributes
  • ✅ Form Elements — Input, select, textarea
  • ✍️ Practice: Build a contact form

📅 Day 11 — Forms Part 2

  • ✅ Input Types — All 20+ types
  • ✅ Input Attributes — Validation, patterns
  • ✍️ Practice: Build a registration form with validation

📅 Day 12 — Responsive & Advanced

  • ✅ HTML Responsive — Media queries
  • ✅ HTML Semantics, Style Guide
  • ✍️ Practice: Make your pages mobile-friendly

📅 Day 13 — Graphics & Media

  • ✅ Canvas, SVG, Video, Audio, YouTube
  • ✅ Entities, Symbols, Emojis
  • ✍️ Practice: Add multimedia to your website

📅 Day 14 — APIs & Final Project

  • ✅ Web APIs, Geolocation, Web Storage
  • ✅ Drag & Drop, Web Workers, SSE
  • ✍️ Final Project: Build a complete portfolio website!
