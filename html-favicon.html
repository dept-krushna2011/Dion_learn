⭐ HTML Favicon

A favicon is a small icon displayed in the browser tab next to the page title. It also appears in bookmarks, history, and browser tabs — helping users identify your site quickly.

🔖 Browser Tab: ⭐ My Website

📝 How to Add a Favicon

Use the <link> tag inside the <head> section with rel="icon":

<head>
  <title>My Website</title>
  <link rel="icon" type="image/x-icon" href="favicon.ico">
</head>
AttributeValueDescription
rel"icon"Tells browser this is a favicon
type"image/x-icon"File type (for .ico files)
href"favicon.ico"Path to the favicon file

📦 Favicon File Formats

FormatExtensionBest For
ICO.icoTraditional, all browsers support
PNG.pngModern, better quality, transparency
SVG.svgScalable, sharp at any size
GIF.gifAnimated favicons
JPEG.jpgNot recommended for favicons

Modern PNG Favicon (Recommended)

<link rel="icon" type="image/png" href="favicon.png">

📐 Favicon Size

The standard favicon size is 16x16 pixels or 32x32 pixels. For modern high-resolution displays, you can provide multiple sizes:

<!-- Standard -->
<link rel="icon" sizes="16x16" href="favicon-16.png">

<!-- High-res -->
<link rel="icon" sizes="32x32" href="favicon-32.png">

<!-- Apple Touch Icon -->
<link rel="apple-touch-icon" href="apple-icon.png">

🛠️ How to Create a Favicon

  1. Design a simple icon (use Canva, Figma, or any image editor)
  2. Keep it small — 16×16 or 32×32 pixels
  3. Use simple shapes — details get lost at small sizes
  4. Save as .png or .ico
  5. Use free online tools like favicon.io or realfavicongenerator.net to convert images to favicons

💡 Pro Tip: You can turn any image into a favicon using favicon.io — just upload, download, and add to your project!
