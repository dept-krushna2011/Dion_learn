📝 HTML Forms

An HTML form is used to collect user input and send it to a server for processing. Forms are everywhere — login pages, search bars, contact forms, checkout pages, and surveys.

🧠 Key Concept: The <form> element is a container for input elements like text fields, checkboxes, radio buttons, and submit buttons. The form itself doesn't display anything — it's the inputs inside that users interact with.

🏗️ Basic Form Structure

<form action="/submit" method="POST">
  <!-- Form elements go here -->
</form>
AttributeDescriptionCommon Values
actionWhere to send the form dataURL like /submit or process.php
methodHTTP method for sending dataGET (visible in URL) or POST (hidden, secure)

📝 Your First Form

Here's a simple form with text input and a submit button:

<form action="/submit" method="POST">
  <label for="name">Name:</label>
  <input type="text" id="name" name="username">
  
  <label for="email">Email:</label>
  <input type="email" id="email" name="email">
  
  <button type="submit">Submit</button>
</form>

🆚 GET vs POST Method

FeatureGETPOST
Data Visible in URL?✅ Yes (in query string)❌ No (hidden in request body)
SecurityLess secureMore secure
Data Limit~2048 charactersNo limit
Bookmarkable?✅ Yes❌ No
Best ForSearch forms, filtersLogin, registration, payments

💡 Rule of Thumb: Use GET when fetching/searching data (no side effects). Use POST when creating/updating data (changes server state).
