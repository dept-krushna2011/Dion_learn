🔤 HTML Charsets

A character set (charset) is a system that maps characters (letters, numbers, symbols) to numbers that computers can understand. The right charset ensures your text displays correctly across all languages.

🧠 Key Point: Without proper charset declaration, your page might show garbled text (like â€™ instead of ') — especially for non-English characters like é, ñ, 中文, or العربية.

🌍 UTF-8 — The Universal Standard

UTF-8 is the default character encoding for HTML5. It covers almost all characters and symbols in the world — from English to Chinese, Arabic, Hindi, emojis, and more.

<meta charset="UTF-8">

💡 Always include this meta tag as the FIRST element inside <head>. It ensures all text, symbols, and emojis display correctly on your page!

📊 Common Character Sets

CharsetDescriptionCharacters Supported
UTF-8Universal standard (HTML5 default)All languages + emojis (✅ Use this!)
ASCIIOldest — English only128 characters (A-Z, 0-9, basic symbols)
ISO-8859-1Latin/Western European256 characters (English + European accents)
Windows-1252Windows Latin-1Similar to ISO-8859-1, Windows specific
Shift-JISJapaneseJapanese characters

⚠️ Important: Always use UTF-8 for new projects. Other charsets are legacy — you only need them when working with very old websites or specific language requirements.

🤔 Why UTF-8 is the Best Choice

AdvantageExplanation
✅ UniversalSupports ALL languages — English, Chinese, Arabic, Hindi, Russian...
✅ Emoji SupportDisplays emojis 😀🚀❤️ without any extra code
✅ Backward CompatibleWorks with ASCII — no changes needed for English text
✅ HTML5 StandardDefault encoding for all modern web browsers
✅ No Conversion NeededSame encoding works across databases, APIs, and file systems

📝 Declaring Charset in HTML

Charset can be declared in different ways depending on the HTML version:

<!-- HTML5 (Recommended) -->
<meta charset="UTF-8">

<!-- HTML4 (Old way) -->
<meta http-equiv="Content-Type" content="text/html; charset=UTF-8">
