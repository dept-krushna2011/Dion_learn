📱 HTML Responsive Web Design

Responsive web design makes your web page look good on all devices — desktops, tablets, and phones. It uses HTML and CSS to automatically resize, hide, shrink, or enlarge content so it looks perfect on any screen.

🧠 Why it matters: Over 60% of web traffic comes from mobile devices. If your website isn't responsive, you're losing more than half your visitors!

📐 Setting the Viewport

The viewport meta tag is the FIRST step to responsive design. It tells the browser how to control the page's dimensions and scaling on different devices.

<meta name="viewport" content="width=device-width, initial-scale=1.0">
PartMeaning
width=device-widthSets page width to follow the device's screen width
initial-scale=1.0Sets the initial zoom level when the page first loads

⚠️ Without this tag: Mobile browsers render the page at a desktop width (like 980px) and scale it down — making text tiny, unreadable, and forcing users to zoom and scroll horizontally.

🖼️ Responsive Images

Images need special handling to scale properly on different screens.

Method 1: Using max-width

The simplest way — image scales down but never exceeds its original size:

<img src="photo.jpg" style="max-width: 100%; height: auto;">

Method 2: Using width: 100%

Image always fills its container — may stretch beyond original size:

<img src="photo.jpg" style="width: 100%;">

Method 3: The <picture> Element

Serve different images for different screen sizes (best for performance):

<picture>
  <!-- Large image for desktops -->
  <source srcset="large.jpg" media="(min-width: 768px)">
  
  <!-- Default small image for mobile -->
  <img src="small.jpg" alt="Photo">
</picture>

📏 Media Queries — The Heart of Responsive Design

Media queries apply different CSS styles based on screen size. This is the most powerful tool for responsive design.

Mobile-First Approach (Recommended)

Write base styles for mobile first, then add complexity for larger screens:

/* Base styles — Mobile First (small screens) */
.container {
  width: 100%;
  padding: 10px;
  font-size: 14px;
}

/* Tablet — 768px and larger */
@media (min-width: 768px) {
  .container {
    width: 80%;
    padding: 20px;
    font-size: 16px;
  }
}

/* Desktop — 1024px and larger */
@media (min-width: 1024px) {
  .container {
    width: 60%;
    max-width: 1200px;
    font-size: 18px;
  }
}

📝 Responsive Text (Fluid Typography)

Use vw (viewport width) units to make text that scales with the screen:

<h1 style="font-size: 5vw;">
  This heading scales with screen width!
</h1>

💡 Tip: 1vw = 1% of viewport width. On a 1000px wide screen, 5vw = 50px. On a 375px phone, 5vw ≈ 19px.

📐 Responsive Layout with Flexbox

Use flex-wrap to automatically stack items on smaller screens:

<style>
  .card-container {
    display: flex;
    flex-wrap: wrap;  /* Cards wrap to next line on small screens */
    gap: 20px;
  }
  .card {
    flex: 1 1 300px;  /* Minimum 300px, grows to fill space */
    padding: 20px;
    background: #f0f0f0;
    border-radius: 8px;
  }
</style>

👁️ Show/Hide Content by Screen Size

Use media queries to show or hide elements on different devices:

/* Hide on mobile, show on desktop */
.desktop-only { display: none; }

@media (min-width: 768px) {
  .desktop-only { display: block; }
}

/* Show on mobile, hide on desktop */
.mobile-only { display: block; }

@media (min-width: 768px) {
  .mobile-only { display: none; }
}
