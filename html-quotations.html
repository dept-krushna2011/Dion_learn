💬 HTML Quotations

HTML provides several elements for marking up quotations, citations, abbreviations, contact information, and text direction.

📜 <blockquote> — Long Quotations

The <blockquote> element defines a section that is quoted from another source. Browsers usually indent blockquote content.

<p>Here is a quote from WWF's website:</p>
<blockquote>
For 60 years, WWF has worked to help people and nature thrive.
As the world's leading conservation organization, WWF works in
nearly 100 countries.
</blockquote>

📟 Browser Output:

Here is a quote from WWF's website:

For 60 years, WWF has worked to help people and nature thrive. As the world's leading conservation organization, WWF works in nearly 100 countries.

💡 Cite Attribute: Use cite="URL" in <blockquote> to reference the source URL. It's not visible but helps search engines.

💬 <q> — Short Inline Quotations

The <q> tag defines a short inline quotation. Browsers automatically add quotation marks around the text.

<p>
  WWF's goal is to: 
  <q>Build a future where people live in harmony with nature.</q>
</p>

📟 Browser Output:

WWF's goal is to: Build a future where people live in harmony with nature.

🔤 <abbr> — Abbreviations

The <abbr> tag defines an abbreviation or acronym. The title attribute shows the full form as a tooltip on hover.

<p>
  <abbr title="HyperText Markup Language">HTML</abbr> is the
  standard markup language for creating web pages.
</p>

📟 Browser Output:

HTML is the standard markup language for creating web pages. (Hover over "HTML" to see the tooltip!)

📍 <address> — Contact Information

The <address> tag defines the contact information for the author/owner of a document or article. Browsers usually display it in italic.

<address>
  Written by John Doe.<br>
  Visit us at:<br>
  Example.com<br>
  Box 564, Disneyland<br>
  USA
</address>

📟 Browser Output:

Written by John Doe.
Visit us at:
Example.com
Box 564, Disneyland
USA

📚 <cite> — Work Title

The <cite> tag defines the title of a creative work (book, poem, song, movie, painting, etc.). Browsers usually display it in italic.

<p>
  <cite>The Scream</cite> by Edvard Munch. 
  Painted in 1893.
</p>

📟 Browser Output:

The Scream by Edvard Munch. Painted in 1893.

↔️ <bdo> — Bi-Directional Override

The <bdo> (Bi-Directional Override) tag overrides the current text direction. Use dir="rtl" for right-to-left text (like Arabic or Hebrew).

<!-- Normal text -->
<p>This text will go left to right.</p>

<!-- Right-to-left override -->
<bdo dir="rtl">This text will go right to left.</bdo>

📟 Browser Output:

This text will go left to right.

This text will go right to left.
