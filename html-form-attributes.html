🔧 HTML Form Attributes

Form attributes control how a form behaves — where data is sent, how it's sent, validation, autocomplete, and more. These attributes are applied to the <form> tag itself.

📋 All Form Attributes

AttributeDescriptionExample
actionURL where form data is sentaction="/submit.php"
methodHTTP method (GET or POST)method="POST"
targetWhere to display the responsetarget="_blank"
autocompleteEnable/disable browser suggestionsautocomplete="on"
novalidateSkip browser validationnovalidate (no value needed)
enctypeHow data is encoded (for file uploads)enctype="multipart/form-data"
nameName of the formname="loginForm"
accept-charsetCharacter encoding for submissionaccept-charset="UTF-8"
relRelationship with linked resourcerel="nofollow"

🎯 action & method — The Core Attributes

These are the two most important form attributes:

<form action="/login" method="POST">
  <!-- inputs here -->
</form>
AttributeWhat It DoesIf Omitted
actionSends data to this URLData is sent to the same page
methodGET = data in URL, POST = data in bodyDefaults to GET

🎯 target Attribute

The target attribute specifies where to open the response after form submission:

ValueBehavior
_selfOpen in same tab (default)
_blankOpen in new tab/window
_parentOpen in parent frame
_topOpen in full window body
<form action="/submit" target="_blank">

🤖 autocomplete Attribute

Controls whether the browser should remember and suggest previously entered values:

<!-- Enable autocomplete (default) -->
<form autocomplete="on">

<!-- Disable autocomplete -->
<form autocomplete="off">

💡 Use autocomplete="off" for sensitive forms (like payment details) or when you don't want the browser to cache user input.

🚫 novalidate Attribute

The novalidate attribute tells the browser not to validate form inputs before submission. It's a boolean attribute — just the name is enough:

<form action="/submit" novalidate>
  <!-- Browser won't check required fields, email format, etc. -->
</form>
