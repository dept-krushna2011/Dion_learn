⚡ HTML Basic Examples

In this chapter, you'll learn the most fundamental HTML tags by looking at simple examples. We'll cover headings, paragraphs, links, images, and buttons — the building blocks of every website!

💡 No prior knowledge needed! Just open a text editor and code along with each example.

📄 HTML Documents

Every HTML document must start with <!DOCTYPE html>. This tells the browser it's an HTML5 document.

<!DOCTYPE html>
<html>
<head>
  <title>My Page</title>
</head>
<body>
  <!-- Content goes here -->
</body>
</html>

🧠 Remember: The <!DOCTYPE html> declaration is NOT an HTML tag — it's an instruction to the browser about what version of HTML the page is written in.

🔤 HTML Headings

Headings are defined with <h1> to <h6> tags. <h1> is the most important, <h6> is the least.

<h1>This is Heading 1 (Largest)</h1>
<h2>This is Heading 2</h2>
<h3>This is Heading 3</h3>
<h4>This is Heading 4</h4>
<h5>This is Heading 5</h5>
<h6>This is Heading 6 (Smallest)</h6>

📟 Browser Output:

This is Heading 1

This is Heading 2

This is Heading 3

This is Heading 4

This is Heading 5
This is Heading 6

🧠 SEO Tip: Use only one <h1> per page — it tells search engines the main topic. Use <h2>-<h6> for sub-headings.

📝 HTML Paragraphs

The <p> tag defines a paragraph. Browsers automatically add space before and after paragraphs.

<p>This is the first paragraph. It contains some text about HTML.</p>
<p>This is the second paragraph. Each paragraph starts on a new line.</p>
<p>HTML is fun and easy to learn!</p>

📟 Browser Output:

This is the first paragraph. It contains some text about HTML.

This is the second paragraph. Each paragraph starts on a new line.

HTML is fun and easy to learn!

🔗 HTML Links

The <a> (anchor) tag creates hyperlinks. The href attribute specifies the destination URL.

<!-- Link to another website -->
<a href="https://www.google.com">Go to Google</a>

<!-- Link that opens in new tab -->
<a href="https://example.com" target="_blank">Open in New Tab</a>

<!-- Email link -->
<a href="mailto:hello@example.com">Send Email</a>

📟 Browser Output:

Go to Google Open in New Tab Send Email

🖼️ HTML Images

The <img> tag embeds images. It's a self-closing (empty) tag — no end tag needed.

<img src="photo.jpg" alt="A beautiful sunset" width="300">
AttributePurposeRequired?
srcPath to the image file✅ Yes
altAlternative text (shown if image fails, helps accessibility & SEO)✅ Yes
widthWidth in pixels❌ Optional
heightHeight in pixels❌ Optional

🔘 HTML Buttons

The <button> tag creates a clickable button.

<button>Click Me!</button>
<button onclick="alert('Hello!')">Show Alert</button>

🎯 Complete Example: All Together

Here's a complete web page using everything you just learned:

<!DOCTYPE html>
<html>
<head>
  <title>My First Web Page</title>
</head>
<body>

  <h1>Welcome to My Website</h1>
  
  <p>Hello! This is my first HTML page. I'm learning web development!</p>
  
  <img src="https://images.unsplash.com/photo-1498050108023-c5249f4df085?w=400" alt="Coding" width="300">
  
  <p>Visit my favorite website: 
    <a href="https://www.google.com">Google</a>
  </p>
  
  <button onclick="alert('Thanks for visiting!')">
    Click for a Surprise!
  </button>

</body>
</html>
