📖 HTML Introduction

HTML is the standard markup language for creating Web pages. It describes the structure of a Web page and consists of a series of elements that tell the browser how to display the content.

💡 Fun Fact: HTML was invented by Sir Tim Berners-Lee in 1991 at CERN. The first ever website (info.cern.ch) is still live today!

🤔 What is HTML?

HTML stands for:

  • Hyper — Links that connect pages together
  • Text — Content (words, images, videos)
  • Markup — Tags that "mark up" or annotate content
  • Language — A system with specific rules (syntax)

🧠 Key Point: HTML is NOT a programming language. It's a markup language. It doesn't do calculations or logic — it simply structures content. Programming logic is handled by JavaScript.

A Simple HTML Document

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My First Web Page</title>
</head>
<body>
  <h1>Hello, World!</h1>
  <p>Welcome to my website.</p>
</body>
</html>

Example Explained Line-by-Line

LineCodeExplanation
1<!DOCTYPE html>Declares this is an HTML5 document (must be first line)
2<html lang="en">Root element — wraps ALL content. lang="en" tells search engines the page is in English
3<head>Contains meta-info (not visible to users) — title, CSS links, scripts
4<meta charset="UTF-8">Sets character encoding to support all languages and emojis
5<meta name="viewport"...>Makes page responsive on mobile devices
6<title>Shows in browser tab — crucial for SEO
7</head>Closes the head section
8<body>Everything VISIBLE on the page goes here
9<h1>Main heading (largest, most important)
10<p>Paragraph of text
11</body>Closes body
12</html>Closes HTML document

🧩 What are HTML Elements?

An HTML element is everything from the start tag to the end tag:

<tagname>Content goes here...</tagname>

Parts of an HTML Element

PartExampleDescription
Start tag<p>Marks the beginning of an element
ContentHello WorldThe actual text or nested elements
End tag</p>Marks the end (has a forward slash)

⚠️ Important: Some elements are empty (self-closing) — they have NO content and NO end tag. Examples: <br> (line break), <hr> (horizontal rule), <img> (image), <input> (form input).

Nested Elements

HTML elements can contain other elements — this is called nesting:

<body>
  <div>
    <h1>Main Heading</h1>
    <p>This is a paragraph inside a div.</p>
  </div>
</body>

Here, <body> is the parent, <div> is the child of body and parent of <h1> and <p>.

🖥️ How Web Browsers Process HTML

When you visit a website, here's what happens step-by-step:

  1. You enter a URL (like google.com) or open an HTML file
  2. The browser fetches the HTML document from a server or your local computer
  3. The browser parses the HTML — reads it top to bottom and builds a DOM Tree (Document Object Model)
  4. The DOM Tree is a hierarchical representation of all elements — parent → child relationships
  5. CSS is applied to style each element (colors, sizes, layout)
  6. JavaScript executes to add interactivity (clicks, animations, dynamic content)
  7. The page renders (paints) on your screen as the final visual result

🧠 DOM = Document Object Model: Think of it as a family tree of HTML elements. The browser uses this tree to understand which element is inside which, and to apply styles and scripts correctly.

💡 Browsers are forgiving: If you make small mistakes (like forgetting a closing tag), modern browsers try to fix them automatically. But don't rely on this — always write valid, clean HTML!

📜 A Brief History of HTML

YearVersionKey Features
1991HTML 1.0Created by Tim Berners-Lee. Basic structure: headings, paragraphs, links — only 18 tags!
1995HTML 2.0Became official standard. Added forms, tables, image maps
1997HTML 3.2W3C standard. More formatting options, applets, better table support
1999HTML 4.01Major update. CSS integration, accessibility features, frames, better forms
2000XHTML 1.0HTML reformulated as XML — stricter rules, must be well-formed
2014HTML5🎯 Current standard! Video, audio, canvas, semantic tags, local storage, geolocation, drag & drop, and more!

🌟 Today: HTML5 is the modern standard used by ALL websites. It's supported by every browser (Chrome, Firefox, Safari, Edge). This entire tutorial teaches HTML5.

💪 Why Should You Learn HTML?

1. It's the Foundation of the Web

Every website — Google, YouTube, Facebook, Amazon — is built with HTML. It's the universal language of the internet. Without HTML, there is no web.

2. Extremely Easy to Learn

You can create your first working web page in under 5 minutes! The syntax is readable and intuitive — even non-programmers can learn it quickly.

3. High Demand Career Skill

Web development is one of the fastest-growing fields globally. HTML is the first skill every web developer learns. The average web developer salary is excellent worldwide.

4. Works with Other Technologies

HTML is the starting point that connects with:

  • CSS — Makes pages beautiful
  • JavaScript — Makes pages interactive
  • Backend languages (Python, PHP, Node.js) — Create dynamic content
  • Frameworks (React, Angular, Vue) — Build complex applications

5. Completely Free

No licenses, no subscriptions, no special software. You can write HTML in Notepad and view it in any browser — 100% free forever!
