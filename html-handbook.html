📖 Chapter 1: What is HTML?

In Simple Words...

Imagine you're building a house:

  • HTML = The walls, roof, doors, and windows (the structure)
  • CSS = The paint, curtains, and decorations (the beauty)
  • JavaScript = The doorbell, light switches, and smart devices (the brains)
🧠 Key Point: HTML is NOT a programming language. It's a markup language — it structures content but doesn't do calculations.

What Does HTML Look Like?

<h1>Welcome to My Website</h1>
<p>This is a paragraph of text.</p>
<button>Click Me!</button>

🌍 Real-World Example: YouTube

When you open YouTube, everything you see is made with HTML:

┌──────────────────────────────────────────┐ │ 🔴 YouTube 🔍 [Search Bar] [🔔] [👤]│ ← <header> ├──────────────────────────────────────────┤ │ ┌──────────┐ ┌──────────┐ ┌──────────┐ │ │ │ Thumbnail│ │ Thumbnail│ │ Thumbnail│ │ ← <div> cards │ │ Video 1 │ │ Video 2 │ │ Video 3 │ │ │ └──────────┘ └──────────┘ └──────────┘ │ ├──────────────────────────────────────────┤ │ About Press Copyright Contact Us │ ← <footer> └──────────────────────────────────────────┘

Every video thumbnail, search bar, button, and text — that's all HTML!

How the Web Works (30 Seconds)

  1. You type youtube.com in your browser
  2. Your browser asks YouTube's server: "Give me the page!"
  3. The server sends back an HTML file
  4. Your browser reads the HTML and displays the page
💡 Fun Fact: The first ever website was created by Tim Berners-Lee in 1991. It's still live at info.cern.ch!

🔧 Chapter 2: Setting Up — Your First Webpage

What You Need

  • ✅ A computer (Windows, Mac, or Linux)
  • ✅ A text editor (We recommend VS Code — it's free!)
  • ✅ A browser (Chrome, Firefox, or Edge)

Your First HTML File

Create a file called index.html and type this:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Website</title>
</head>
<body>
    <h1>Hello, World! 🌍</h1>
    <p>I just created my first webpage!</p>
</body>
</html>

What Each Line Means

CodeWhat It Does
<!DOCTYPE html>Tells browser: "This is HTML5"
<html>The root — wraps everything
<head>Info about the page (not visible)
<title>Text shown in browser tab
<body>Everything VISIBLE on the page
<h1>Main heading (biggest text)
<p>Paragraph of text
🌍 Real-World: Every website you visit — Google, Facebook, Amazon — starts with this exact same structure. They just have thousands more lines inside!

🧱 Chapter 3: Basic Building Blocks

Headings (h1 to h6)

Think of headings like newspaper headlines. h1 is the main title, h2 is a sub-title, and so on.

<h1>Main Title (Biggest)</h1>
<h2>Section Heading</h2>
<h3>Sub-section</h3>
<h4>Smaller Heading</h4>
<h5>Even Smaller</h5>
<h6>Smallest Heading</h6>
💡 SEO Tip: Use only ONE <h1> per page. Google uses it to understand what your page is about.

Paragraphs

<p>This is a paragraph. Browsers automatically add space between paragraphs.</p>
<p>This is another paragraph.</p>

🔗 Chapter 4: Links & Images

Hyperlinks — The "Web" in Web

Links connect pages together. Without them, there is no "world wide web."

<!-- Link to Google -->
<a href="https://google.com">Go to Google</a>

<!-- Link that opens in NEW tab -->
<a href="about.html" target="_blank">About Us (New Tab)</a>

<!-- Email link -->
<a href="mailto:hello@example.com">Email Us</a>

<!-- Phone link (works on mobile) -->
<a href="tel:+911234567890">Call Us</a>
🌍 Real-World: Every time you click a search result on Google, you're clicking an <a> tag!

Images

<img src="sunset.jpg" alt="Beautiful orange sunset" width="400">
AttributeRequired?Purpose
src✅ YesPath to the image file
alt✅ Highly RecommendedText description (for blind users & SEO)
width❌ OptionalWidth in pixels
height❌ OptionalHeight in pixels
🧠 Always add alt text! It helps visually impaired users (screen readers read it aloud) and Google uses it to understand your images.

Image as a Link

<a href="product.html">
    <img src="product.jpg" alt="Buy this product">
</a>

📋 Chapter 5: Lists & Tables

Lists — 3 Types

1. Unordered List (Bullet Points)

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

2. Ordered List (Numbered)

<ol>
    <li>Wake up</li>
    <li>Brush teeth</li>
    <li>Code!</li>
</ol>

3. Description List (Term + Definition)

<dl>
    <dt>HTML</dt>
    <dd>Structures web pages</dd>
    <dt>CSS</dt>
    <dd>Styles web pages</dd>
</dl>
🌍 Real-World: Restaurant menus use lists. Recipe websites use ordered lists for steps. Wikipedia uses description lists for terms.

Tables — Organizing Data

<table>
    <tr>
        <th>Name</th>
        <th>Score</th>
    </tr>
    <tr>
        <td>Virat Kohli</td>
        <td>82</td>
    </tr>
    <tr>
        <td>Rohit Sharma</td>
        <td>120</td>
    </tr>
</table>
TagMeaning
<table>Creates the table
<tr>Table Row
<th>Table Header (bold, centered)
<td>Table Data (regular cell)

Merging Cells

<td colspan="2">Spans 2 columns</td>  <!-- Merge horizontally -->
<td rowspan="2">Spans 2 rows</td>     <!-- Merge vertically -->
🌍 Real-World: Cricket scorecards, exam results, product comparison charts, and invoice tables all use HTML tables.

📝 Chapter 6: Forms — Getting User Input

What is a Form?

A form collects information from users. Every time you log in, search, sign up, or post a comment — you're using an HTML form.

Basic Login Form

<form action="/login" method="POST">
    <label>Email:</label>
    <input type="email" placeholder="Enter email" required>
    
    <label>Password:</label>
    <input type="password" placeholder="Enter password" required>
    
    <button type="submit">Login</button>
</form>

All Input Types

dateDate picker

radioSingle choice (circle)

Important Form Elements

<!-- Dropdown -->
<select>
    <option>India</option>
    <option>USA</option>
    <option>UK</option>
</select>

<!-- Multi-line text -->
<textarea rows="4" placeholder="Your message..."></textarea>

<!-- Label (clickable text for inputs) -->
<label for="email">Email Address</label>
<input type="email" id="email">

Validation Attributes

🌍 Real-World: Google's search bar is an <input type="text">. Amazon's login is a form with email and password inputs. Every checkout page you've ever used is an HTML form!

🏗️ Chapter 7: Layout & Structure

Div & Span — The Containers

<div> is a block container — it takes the full width and starts on a new line.

<span> is an inline container — it only takes as much space as needed.

<div style="background:purple;color:white;padding:20px;">
    <h2>Section Title</h2>
    <p>This is inside a div.</p>
</div>

<p>This is <span style="color:red;">red text</span> inside a paragraph.</p>

Semantic Layout Tags

HTML5 introduced meaningful tags that describe what each section IS:

TagWhat It Means
<header>Top section — logo, title, nav
<nav>Navigation menu
<main>Unique page content (only ONE!)
<section>A thematic group of content
<article>Independent content (blog post)
<aside>Sidebar, related links, ads
<footer>Bottom section — copyright, links

Complete Page Layout

<body>
    <header>Logo & Site Name</header>
    <nav>Home | About | Contact</nav>
    <main>
        <article>Main blog post</article>
        <aside>Sidebar with links</aside>
    </main>
    <footer>© 2026 My Website</footer>
</body>
┌──────────────────────────────────┐ │ <header> │ ← Logo, site name ├──────────────────────────────────┤ │ Home | About | Contact │ ← <nav> ├────────────────┬─────────────────┤ │ │ │ │ <main> │ <aside> │ │ Main content │ Sidebar │ │ │ │ ├────────────────┴─────────────────┤ │ <footer> │ ← Copyright, links └──────────────────────────────────┘
🌍 Real-World: Every news website (BBC, CNN, Times of India) uses this exact structure — header with logo, nav with categories, main article, sidebar with related news, and footer.

🎬 Chapter 8: Multimedia — Video & Audio

Embedding Video

<video width="640" controls>
    <source src="myvideo.mp4" type="video/mp4">
    Your browser doesn't support video.
</video>

Video Attributes

AttributeWhat It Does

Embedding YouTube Videos

<iframe width="560" height="315"
    src="https://www.youtube.com/embed/VIDEO_ID"

</iframe>

Embedding Audio

<audio controls>
    <source src="song.mp3" type="audio/mpeg">
    Your browser doesn't support audio.
</audio>
🌍 Real-World: Spotify's web player uses <audio>. YouTube uses <iframe>. Netflix uses <video>. Every video you watch online uses one of these tags!

Responsive Design — Works on All Screens

/* Mobile-first styles */
.container { width: 100%; }

/* Tablets and larger */
@media (min-width: 768px) {
    .container { width: 80%; }
}

/* Desktop */
@media (min-width: 1024px) {
    .container { max-width: 1200px; }
}
💡 Key Rule: Always design for mobile first, then add styles for larger screens using @media queries.
