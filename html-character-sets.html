🔤 HTML Character Sets

A character set is a system that maps characters to numbers so computers can store and display text. The right character set ensures your text displays correctly in all languages.

🧠 In Simple Words: Computers only understand numbers. A character set tells the computer: "Number 65 = A, Number 66 = B, Number 128512 = 😀". UTF-8 is the universal character set that covers ALL languages!

✅ UTF-8 — The Universal Standard

UTF-8 is the default character encoding for HTML5. It covers:

  • ✅ All Latin characters (English, French, Spanish, German...)
  • ✅ All Cyrillic characters (Russian, Bulgarian, Serbian...)
  • ✅ All Asian characters (Chinese, Japanese, Korean, Hindi, Arabic...)
  • ✅ All emojis (😀 🚀 ❤️ 🔥)
  • ✅ All mathematical symbols (∀ ∂ ∑ ∞)
  • ✅ Backward compatible with ASCII
<meta charset="UTF-8">

📝 Declaring Character Set

<!-- HTML5 (Recommended) -->
<meta charset="UTF-8">

<!-- HTML4 (Old way) -->
<meta http-equiv="Content-Type" content="text/html; charset=UTF-8">

💡 Best Practice: Always put <meta charset="UTF-8"> as the FIRST element inside <head>. This ensures the browser knows the encoding before it reads any text!
