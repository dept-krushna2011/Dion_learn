🎨 HTML Styles

The HTML style attribute is used to add styles to an element — such as color, font, size, and more. It's a way to apply CSS directly to an HTML element.

<tagname style="property: value;">

🧠 Note: The style attribute uses CSS syntax — property: value;. You can add multiple styles separated by semicolons.

🎨 Background Color

The CSS background-color property sets the background color of an element.

<body style="background-color: powderblue;">

<p style="background-color: tomato;">
  This paragraph has a tomato background.
</p>

📟 Browser Output:

This paragraph has a tomato background.

🔤 Text Color

The CSS color property defines the text color.

<p style="color: blue;">Blue text</p>
<p style="color: red;">Red text</p>
<p style="color: #8b5cf6;">Purple text (HEX)</p>

📟 Browser Output:

Blue text

Red text

Purple text (HEX)

✍️ Fonts

The CSS font-family property defines the font. font-size defines the text size. text-align defines the alignment.

<p style="font-family: verdana;">Verdana font</p>
<p style="font-size: 30px;">30px text</p>
<p style="text-align: center;">Centered text</p>

📟 Browser Output:

Verdana font

30px text

Centered text

📐 Three Ways to Add CSS to HTML

There are three ways to apply CSS to HTML. The style attribute is just one of them — called Inline CSS.

MethodWhereBest ForExample
InlineInside HTML tagQuick, single-element styling<p style="color:red;">
InternalIn <style> in <head>Single page styling<style>p {color:red;}</style>
ExternalSeparate .css fileMultiple pages (Recommended)<link href="style.css">

💡 Best Practice: For professional projects, use External CSS. It keeps HTML clean and allows you to style multiple pages from one file. Inline styles are best for quick testing only.
