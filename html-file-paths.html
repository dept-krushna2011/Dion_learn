📂 HTML File Paths

A file path describes the location of a file in a website's folder structure. You use file paths when linking to external files like images, CSS stylesheets, JavaScript files, and other web pages.

📐 Types of File Paths

TypeDescriptionExample
Absolute PathFull URL including protocolhttps://example.com/images/pic.jpg
Relative PathPath relative to current pageimages/pic.jpg
Root-Relative PathPath relative to website root/images/pic.jpg

🌐 Absolute File Paths

An absolute path is the full URL to a file. Use it for files hosted on other websites.

<img src="https://www.example.com/images/photo.jpg" alt="Photo">
<a href="https://www.google.com">Google</a>

⚠️ Caution: Absolute paths break if the external website moves or deletes the file. Use them only for external resources you don't control, or for CDN links.

📁 Relative File Paths

A relative path is relative to the current page. It's the best choice for files within your own website.

Same Folder

<!-- File in the SAME folder as current page -->
<img src="photo.jpg">
<a href="about.html">About</a>

Subfolder (Go INTO a folder)

<!-- File in "images" subfolder -->
<img src="images/photo.jpg">
<a href="pages/contact.html">Contact</a>

Parent Folder (Go UP one level)

<!-- Go UP one level (../) -->
<img src="../photo.jpg">

<!-- Go UP two levels (../../) -->
<img src="../../images/photo.jpg">

🔣 Path Symbols Cheat Sheet

SymbolMeaningExampleGoes to
(nothing)Same folderphoto.jpgCurrent folder
foldername/Into subfolderimages/photo.jpgimages folder
../Up one level../photo.jpgParent folder
../../Up two levels../../photo.jpgGrandparent folder
/Website root/images/photo.jpgFrom root folder

📏 Best Practices

  • ✅ Use relative paths for files within your own website
  • ✅ Use absolute paths for external resources (CDN, other websites)
  • ✅ Use forward slashes (/) — not backslashes (\)
  • ✅ Keep folder names lowercase, no spaces (use hyphens instead)
  • ❌ Don't use absolute paths for local files — they break when you move the site

💡 Pro Tip: Use root-relative paths (starting with /) for large websites. They work from any page depth and make moving files easier.
