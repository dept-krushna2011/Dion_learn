🌐 Build Your First Website

Let's build a complete, professional website from scratch! By the end of this guide, you'll have a fully functional website you can host online and share with the world.

🧠 What You'll Build: A personal portfolio website with Home, About, Projects, and Contact pages — using only HTML, CSS, and a touch of JavaScript!

📁 Step 1: Plan Your Website Structure

Every website starts with a plan. Here's the structure we'll build:

my-website/
├── index.html          (Home page)
├── about.html          (About page)
├── projects.html       (Projects page)
├── contact.html        (Contact page)
├── css/
│   └── style.css       (All styling)
├── images/
│   └── (your photos)
└── js/
    └── script.js       (Interactivity)

📝 Step 2: Create the Home Page (index.html)

The home page is your first impression. It should have:

  • Navigation bar with links to all pages
  • Hero section with your name and tagline
  • Brief introduction
  • Call-to-action button

📄 index.html

Create a file named index.html — this is the first page browsers look for!

🎨 Step 3: Add CSS Styling (style.css)

Make your website beautiful! Key things to style:

  • Colors, fonts, and backgrounds
  • Navigation bar — sticky, styled links
  • Hero section — large text, centered content
  • Cards, buttons, and hover effects
  • Responsive design for mobile

📄 Step 4: Create Additional Pages

PageContent
about.htmlYour bio, skills list, education, experience
projects.htmlShowcase 3-5 projects with images, descriptions, links
contact.htmlContact form (name, email, message), social links

🚀 Step 5: Host Your Website Online

Make your website live on the internet — for free!
