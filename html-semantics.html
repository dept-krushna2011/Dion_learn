🧠 HTML Semantics

Semantic HTML means using HTML elements that clearly describe their meaning — both to the browser and to the developer. Instead of using <div> for everything, you use tags like <header>, <nav>, <article> that tell you exactly what that section is.

🧠 Simple Rule: Semantic = meaningful. A <article> tag tells you "this is an article". A <div> tag tells you... nothing. It's just a box.

🤔 Why Use Semantic HTML?

BenefitWho It HelpsHow
🔍 SEOSearch Engines (Google, Bing)Understand page structure, rank content better
♿ AccessibilityScreen reader usersNavigate by landmarks (header, nav, main, footer)
👨‍💻 ReadabilityDevelopers (you & team)Instantly understand page structure
🔧 MaintainabilityFuture youEasier to update and debug clean code

🆚 Semantic vs Non-Semantic

Semantic (Meaningful)Non-Semantic (Generic)
<header><div id="header">
<nav><div id="nav">
<main><div id="content">
<article><div class="post">
<section><div class="section">
<aside><div class="sidebar">
<footer><div id="footer">

📋 All HTML5 Semantic Elements

ElementDescriptionUse Case
<header>Introductory content or navigationPage header, article header
<nav>Major navigation linksMenu, table of contents
<main>Unique content of the page (only ONE!)Main content area
<section>Thematic grouping with a headingChapters, tabs, grouped content
<article>Independent, self-contained contentBlog post, news article, comment
<aside>Content indirectly related to main contentSidebar, related links, ads
<footer>Footer for its nearest sectioning contentPage footer, article footer
<figure>Self-contained content (image, diagram)Image with caption
<figcaption>Caption for <figure>Image description
<time>Date/timePublish date, event time
<mark>Highlighted textSearch result highlights
<details>Expandable/collapsible contentFAQ, spoiler text
<summary>Summary/heading for <details>Clickable heading

📝 Semantic Page Example

<!DOCTYPE html>
<html lang="en">
<head>...</head>
<body>

  <header>
    <h1>My Blog</h1>
    <nav>
      <a href="/">Home</a>
      <a href="/about">About</a>
    </nav>
  </header>

  <main>
    <article>
      <h2>Post Title</h2>
      <time datetime="2026-05-22">May 22, 2026</time>
      <p>Article content...</p>
      <figure>
        <img src="photo.jpg" alt="Photo">
        <figcaption>Image caption</figcaption>
      </figure>
    </article>
  </main>

  <aside>
    <h3>Related Posts</h3>
  </aside>

  <footer>
    <p>© 2026 My Blog</p>
  </footer>

</body>
</html>

📋 Semantics Quick Reference

RuleExplanation
✅ Use <main> only ONCEIt wraps the unique content of the page
✅ Every <section> should have a headingSection represents a thematic grouping
✅ <div> is still OK — when no semantic tag fitsFor generic containers without meaning
✅ <article> should make sense on its ownCould be republished independently
❌ Don't use semantic tags just for stylingUse CSS for appearance, HTML for meaning
