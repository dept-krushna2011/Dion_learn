🏗️ HTML Layout

HTML layout refers to the arrangement of elements on a web page. A well-structured layout makes content easy to read, navigate, and understand. Modern HTML uses semantic elements and CSS for layouts.

🧱 Semantic Layout Elements

HTML5 introduced semantic elements that clearly describe their purpose:

ElementPurposeTypical Content
<header>Top sectionLogo, navigation, title
<nav>Navigation menuLinks to pages/sections
<main>Main contentUnique page content (only ONE!)
<section>Thematic groupingRelated content with a heading
<article>Independent contentBlog post, news article
<aside>SidebarRelated links, ads, widgets
<footer>Bottom sectionCopyright, contact, links

📐 Visual Page Structure

<header> — Logo & Title
<nav> — Home | About | Contact
<main> — Main Content
<section> — Topic 1
<article> — Blog Post
<aside> — Sidebar
<footer> — Copyright & Links

🔧 CSS Layout Techniques

TechniqueCSS PropertyBest For
Flexboxdisplay: flex;1D layouts — rows OR columns
Griddisplay: grid;2D layouts — rows AND columns
Floatfloat: left/right;Legacy — avoid for new layouts
Positionposition: absolute/fixed;Specific element placement

Flexbox Example

<style>
  .container {
    display: flex;
    gap: 20px;
  }
  .sidebar { flex: 1; }
  .main { flex: 3; }
</style>

Grid Example

<style>
  .container {
    display: grid;
    grid-template-columns: 1fr 3fr;
    gap: 20px;
  }
</style>

📝 Complete Layout Example

<!DOCTYPE html>
<html>
<head><title>My Layout</title></head>
<body>

  <header>
    <h1>My Website</h1>
  </header>

  <nav>
    <a href="#">Home</a> |
    <a href="#">About</a> |
    <a href="#">Contact</a>
  </nav>

  <main>
    <article>
      <h2>Article Title</h2>
      <p>Article content...</p>
    </article>
  </main>

  <footer>
    <p>© 2026 My Website</p>
  </footer>

</body>
</html>

📋 Layout Quick Reference

ElementKey Rule
<header>Can be used multiple times (page header, article header)
<main>Only ONE per page — wraps unique content
<nav>For major navigation blocks only
<aside>Content indirectly related to main content
<footer>Can be used multiple times
