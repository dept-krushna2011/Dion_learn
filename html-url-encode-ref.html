🔗 HTML URL Encode Reference

URLs can only contain ASCII characters. URL encoding converts unsafe characters into a % followed by two hexadecimal digits. This reference shows the most common encoded characters.

⚙️ JavaScript URL Encoding

MethodWhat It EncodesExample
encodeURIComponent()Encodes special characters for URL parametersencodeURIComponent('hello world!') → 'hello%20world%21'
encodeURI()Encodes a full URL (keeps structure intact)encodeURI('https://example.com/hello world') → 'https://example.com/hello%20world'

📋 URL Encode Quick Reference

RuleDetails
✅ URLs use ASCII onlyNon-ASCII characters must be encoded
✅ Space becomes %20Or + in form data
✅ Use encodeURIComponent()For encoding query parameters in JavaScript
✅ Safe characters: A-Z, a-z, 0-9, -, _, ., ~These don't need encoding

💡 Pro Tip: When building URLs dynamically in JavaScript, always use encodeURIComponent() on user input before adding it to a URL. This prevents errors with spaces and special characters!
