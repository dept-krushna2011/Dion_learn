🖱️ HTML Drag and Drop

The Drag and Drop API lets users grab an element and move it to another location on the page. It's what powers apps like Trello, file uploaders, and interactive games!

🧠 In Simple Words: Make an element draggable="true" — then users can pick it up and drop it somewhere else. You use JavaScript events to control what happens.

📝 How Drag and Drop Works — 2 Simple Steps

Step 1: Make Something Draggable

<div draggable="true" ondragstart="drag(event)">
  Drag me!
</div>

Step 2: Make a Drop Zone

<div ondragover="allowDrop(event)" ondrop="drop(event)">
  Drop here!
</div>

🔧 Drag Events — The Complete List

EventWhen It Fires
dragstartUser starts dragging an element
dragElement is being dragged (continuously)
dragenterDragged element enters a drop zone
dragoverDragged element is over a drop zone (continuously)
dragleaveDragged element leaves a drop zone
dropElement is dropped on a drop zone
dragendUser releases the mouse (end of drag)
